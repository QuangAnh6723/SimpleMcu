# W25Q128 - Datasheet Summary (SPI NOR Flash)

## 1) SPI Configuration

### 1.1 Interface Mode
- Memory type: 128 Mbit NOR Flash (`16 MByte`), supporting `SPI / Dual SPI / Quad SPI`.
- Supported SPI clock modes: `SPI mode 0` (`CPOL=0, CPHA=0`) and `SPI mode 3` (`CPOL=1, CPHA=1`).
- Data order: `MSB first`.
- `CS#` must remain low for the full command + address + data transaction frame.

### 1.2 Recommended STM32 SPI Setup (Single-bit SPI)
- `Data size`: 8-bit.
- `NSS`: Software-controlled (GPIO controls `CS#`).
- `First bit`: MSB.
- `Baud rate`: start at `<= 10 MHz` during init/identification, then increase (20/40/80 MHz) based on PCB signal quality.
- `CRC`: Disabled.

### 1.3 Basic Command Flow
1. Check device ID with `0x9F` (JEDEC ID).
2. Before any Program/Erase operation, send `Write Enable (0x06)`.
3. Program data with `Page Program (0x02)` per `256-byte` page.
4. Erase using `Sector Erase 4KB (0x20)` / `Block Erase 32KB (0x52)` / `Block Erase 64KB (0xD8)` / `Chip Erase (0xC7 or 0x60)`.
5. Poll BUSY bit (S0) in Status Register-1 via `Read Status Register-1 (0x05)`.

### 1.4 Common SPI Command Table
| Command | Opcode | Description |
|---|---:|---|
| Write Enable | `0x06` | Enable write/erase (set WEL) |
| Write Disable | `0x04` | Disable write/erase |
| Read Status Register-1 | `0x05` | Read BUSY, WEL, BP bits |
| Read Status Register-2 | `0x35` | Read QE, SUS, etc. |
| Read Status Register-3 | `0x15` | Read WPS, DRV, etc. |
| Write Status Registers | `0x01` / `0x31` / `0x11` | Write SR1/SR2/SR3 |
| Read Data | `0x03` | Normal read (no dummy cycle) |
| Fast Read | `0x0B` | High-speed read (with dummy cycles) |
| Page Program | `0x02` | Program up to 256 bytes per page |
| Sector Erase 4KB | `0x20` | Erase one sector |
| Block Erase 32KB | `0x52` | Erase 32KB block |
| Block Erase 64KB | `0xD8` | Erase 64KB block |
| Chip Erase | `0xC7` / `0x60` | Erase entire chip |
| JEDEC ID | `0x9F` | Read manufacturer/device ID |
| Unique ID | `0x4B` | Read 64-bit unique ID |
| Enable Reset | `0x66` | Enable reset sequence |
| Reset Device | `0x99` | Reset the device |

## 2) Pin Diagram (Pinout)

### 2.1 8-pin Package (SOIC-8 / WSON-8)
| Pin | Symbol | Function |
|---:|---|---|
| 1 | `CS#` | Chip Select (active low) |
| 2 | `DO/IO1` | MISO in standard SPI mode |
| 3 | `WP#/IO2` | Write Protect or IO2 in Quad mode |
| 4 | `GND` | Ground |
| 5 | `DI/IO0` | MOSI in standard SPI mode |
| 6 | `CLK` | SPI clock |
| 7 | `HOLD#/RESET#/IO3` | Bus hold / reset (device option) / IO3 in Quad mode |
| 8 | `VCC` | Supply voltage |

### 2.2 Typical STM32 Wiring (1-bit SPI)
- `CS#` -> any GPIO output (dedicated pin recommended, avoid hardware NSS).
- `CLK` -> `SPIx_SCK`.
- `DI/IO0` -> `SPIx_MOSI`.
- `DO/IO1` -> `SPIx_MISO`.
- `WP#/IO2` and `HOLD#/IO3`: pull up to VCC through resistors (typically `4.7k-10k`) if Quad mode is not used.

## 5) Quick Implementation Notes
- After system reset, read `JEDEC ID (0x9F)` to verify communication.
- Every Program/Erase operation should follow: `WREN -> Command -> Poll BUSY=0`.
- Do not program more than 256 bytes in one `Page Program` command (overflow wraps within the same page).
- If Quad SPI is used, set `QE` and configure MCU GPIO/alternate functions accordingly.

## 6) Simple MCU Read/Write Flow

### 6.1 MCU Read Flow (Single SPI)
1. Wait until device is ready (`BUSY=0`, command `0x05`).
2. Pull `CS#` low.
3. Send read command (`0x03` for normal read, or `0x0B` for fast read).
4. Send 24-bit address: `A23:A16`, `A15:A8`, `A7:A0`.
5. If using `0x0B`, send required dummy byte(s).
6. Receive `N` data bytes.
7. Pull `CS#` high.

Minimal sequence:

```text
WAIT_READY -> CS_LOW -> CMD(READ) -> ADDR24 -> [DUMMY] -> RX(N) -> CS_HIGH
```

### 6.2 MCU Write Flow (Page Program)
1. Optional but recommended: erase sector/block first if target area is not blank (`0xFF`).
2. Wait until ready (`BUSY=0`).
3. Send `Write Enable (0x06)`.
4. Pull `CS#` low.
5. Send `Page Program (0x02)` + 24-bit start address.
6. Send up to `256` bytes within the same page.
7. Pull `CS#` high.
8. Poll `BUSY` (`0x05`) until complete.
9. Verify by reading back and comparing data.

Minimal sequence:

```text
[ERASE_IF_NEEDED] -> WAIT_READY -> WREN -> CS_LOW -> CMD(PP) -> ADDR24 -> TX(N<=256) -> CS_HIGH -> POLL_BUSY -> VERIFY
```

### 6.3 Page Boundary Rule (Important)
- A single `Page Program (0x02)` must not cross a page boundary.
- Compute allowed bytes per transaction:

```text
page_offset = addr % 256
chunk       = min(remaining, 256 - page_offset)
```

- Loop write operations until all bytes are programmed.

### 6.4 Practical MCU Driver Pseudocode

```c
int w25q_read(uint32_t addr, uint8_t *buf, size_t len) {
	wait_ready();
	cs_low();
	spi_tx(0x03);
	spi_tx((addr >> 16) & 0xFF);
	spi_tx((addr >> 8) & 0xFF);
	spi_tx(addr & 0xFF);
	spi_rx(buf, len);
	cs_high();
	return 0;
}

int w25q_write(uint32_t addr, const uint8_t *buf, size_t len) {
	while (len) {
		size_t page_off = addr & 0xFF;
		size_t chunk = (len < (256 - page_off)) ? len : (256 - page_off);

		wait_ready();
		write_enable();

		cs_low();
		spi_tx(0x02);
		spi_tx((addr >> 16) & 0xFF);
		spi_tx((addr >> 8) & 0xFF);
		spi_tx(addr & 0xFF);
		spi_tx_buf(buf, chunk);
		cs_high();

		wait_ready();

		addr += chunk;
		buf  += chunk;
		len  -= chunk;
	}
	return 0;
}
```
